# The host tools the suite's rows need, and where the Linux CI job gets each.
# One line per item, fields separated by "|":
#   need | ubuntu-package | kind | note
# "need" is the name a row declares (needs("gdb") in the code, "needs": ["gdb"]
# in a manifest row of tests/harness) or the name a display-layer gate of
# tests/x11 and tests/wayland reports.  tests/check-ci-tools.sh keeps this
# record, the manifests and .github/workflows/linux.yml equal, offline: a need
# with no line here, a package the job does not install, or a job whose
# XWPE_TEST_TOOLS_EXPECTED differs from the lines below, fails.
#
# kind:
#   apt        installed by the job (the package is in its apt-get list).  A
#              row of this need that skips on the job is a FAIL, not a
#              declared absence: the image is wrong.
#   layer      the same, for a tool of a display layer gate (tests/x11/conftest.py,
#              tests/wayland/conftest.py).  No manifest row names it; the gate
#              fails the session instead of skipping when the job expects it.
#   built      installed by the job, but not from a package: the job runs the
#              command the note names after "run: ", at the version
#              tests/ci-versions.txt records.  Expected like an apt tool, so a
#              row that skips for it is a FAIL and not a declared absence.
#   base       on every Linux host the suite runs on (shell, compiler, git,
#              the terminfo tools).  Not installed by name, not declared by a
#              row, not expected.
#   image      on the GitHub runner image, not installed by the job (the JDK,
#              Go, a Rust toolchain).  A row that needs it declares it, so a
#              host without it reads BLOCKED.  Not expected.
#   absent:R   not installed by the job, for the reason R.  A row that needs it
#              declares it, so its skip reads BLOCKED and is named in the report.
#   condition  not a program: a fact about the host or the build.
#
# A note that starts with "run: " names a command the job must also run
# (the package alone is not enough).
#
# Ubuntu 26.04 (resolute) package names and components read on
# packages.ubuntu.com on 2026-11-22; the first CI run on this image is the proof
# that each installed version is usable.
#
